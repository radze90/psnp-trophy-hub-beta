# Trophy Deck

Trophy Deck ergänzt PSNProfiles um ein anpassbares Deck, persönliche Notizen und frei anordbare Profilbereiche. Es kann zusammen mit PSNP+ verwendet werden.

## Installation

1. Installiere [Tampermonkey](https://www.tampermonkey.net/), falls die Erweiterung noch nicht in deinem Browser vorhanden ist.
2. Öffne **[Trophy Deck installieren](https://raw.githubusercontent.com/radze90/psn-trophy-deck/main/Trophy-Deck-Beta.user.js)** und bestätige die Installation in Tampermonkey.
3. Öffne oder aktualisiere [PSNProfiles](https://psnprofiles.com/). Die Sprache richtet sich zunächst nach deinem Browser und kann in den Einstellungen geändert werden.

Bei Chrome und anderen Chromium-basierten Browsern muss gegebenenfalls **„Nutzerskripts zulassen“** oder der Entwicklermodus aktiviert werden. Details findest du in der [Tampermonkey-Anleitung](https://www.tampermonkey.net/faq.php?locale=de&q=Q209).

## Datenschutz

Einstellungen, Notizen, Links, Favoriten und Nutzungsstatistiken werden lokal in deinem Browser gespeichert. Trophy Deck sendet sie nicht automatisch an Dritte. Nutzungsstatistiken kannst du bei Bedarf selbst exportieren und weitergeben. Beim Installieren und Aktualisieren werden das Userscript und die Sprachdateien von GitHub geladen. Selbst hinzugefügte Links öffnen ihr jeweiliges Ziel erst beim Anklicken.
