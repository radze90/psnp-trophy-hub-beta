# Trophy Hub Beta

Trophy Hub ergänzt PSNProfiles um ein anpassbares Deck, persönliche Notizen und frei anordbare Profilbereiche. Es kann zusammen mit PSNP+ verwendet werden.

## Installation

1. Installiere [Tampermonkey](https://www.tampermonkey.net/), falls die Erweiterung noch nicht in deinem Browser vorhanden ist.
2. Öffne **[Trophy Hub Beta installieren](https://raw.githubusercontent.com/radze90/psnp-trophy-hub-beta/main/Trophy-Hub-Beta.user.js)** und bestätige die Installation in Tampermonkey.
3. Öffne oder aktualisiere [PSNProfiles](https://psnprofiles.com/). Die Sprache richtet sich zunächst nach deinem Browser und kann in den Einstellungen geändert werden.

Bei Chrome und anderen Chromium-basierten Browsern muss gegebenenfalls **„Nutzerskripts zulassen“** oder der Entwicklermodus aktiviert werden. Details findest du in der [Tampermonkey-Anleitung](https://www.tampermonkey.net/faq.php?locale=de&q=Q209).

## Datenschutz

Einstellungen, Notizen, Links, Favoriten, Nutzungsstatistiken und öffentliche Spieldaten besuchter PSNProfiles-Seiten werden lokal in deinem Browser gespeichert. Trophy Hub sendet sie nicht automatisch an Dritte. Nutzungsstatistiken kannst du bei Bedarf selbst exportieren und weitergeben. Beim Installieren und Aktualisieren werden das Userscript und die Sprachdateien von GitHub geladen. Selbst hinzugefügte Links öffnen ihr jeweiliges Ziel erst beim Anklicken.
